Logo → system

How the mark maps to the ramps

The product system harmonises the logo's organic gradients into ten disciplined ramps. Two contexts, two vocabularies: logo hexes for the mark itself — system tokens for everything else. Never mix them in the same surface.

When to use logo hexes

Reproducing the mark itself: favicons, app icons, watermark bugs, embroidery/print of the logo, brand-mark animations. The mark's gradients (#0096DB→#00B2EE, #FFB600→#FFCC00) belong only inside the mark's silhouette.

When to use system tokens

Everything else: UI, web sections, charts, pills, video overlays, social graphics. The 400-step brand anchors (signal #01B3F6, crew #18C95C, beacon #FFC500, cargo #FF6A04) are the public face of each module — tuned for screens and contrast math.

Rule: Logo hexes never appear in component code or section backgrounds. If a design calls for "logo green" outside the mark, the answer is crew-500 #0F9B45 (UI) or crew-400 #18C95C (brand accent) — not #019934. Heritage values exist so the mark renders true; the ramps exist so everything around it stays accessible and themeable.

01 — Primitive ramps

Ten palettes, ten stops each

Every colour token in the product resolves to one of these ramps. Never reference raw hex in components — always go through the semantic layer. "Aa" badges show which text colour passes WCAG AA on each stop. Click any swatch to copy its hex.

Usage principle

Primitives are the bedrock. Reference them only when defining semantic tokens — never directly in component code. This is what makes theming, mode-switching, and future rebasing possible.

Brand anchors

Each palette has a "brand" step — the stop used in logos, iconography, and high-visibility UI, marked with a green badge beside the ramp name.

02 — Core identity

Six colours, one voice

Operational Navy is the canvas the whole product lives on. Voyage Violet owns every product-layer and interactive moment. The four module anchors follow the brand spectrum left to right.

03 — Module colours

One palette per module

Every FrontM module owns a palette and a brand anchor step. Use the accent for pills, icon fills, active tabs. Use text-safe for coloured copy on white. Use soft bg for tinted section backgrounds on light surfaces.

04 — Dark surface ladder

Six steps, one direction

Each step is lighter than the one below. Abyss for sunken/inset elements, Helm for floating panels and tooltips. Never skip steps — the graduation creates spatial hierarchy without borders.

07 — Gradients & glows

Three gradients, three glows

Tier 3 effect tokens — brand energy, not structure. Spectrum for brand communication, Operational for backgrounds, Intelligence for AI/data moments. Glows only on key CTAs and live states.

Spectrum
--gradient-spectrum
#01B3F6 → #18C95C → #FFC500 → #FF6A04. Hero bars, brand moments. Derives from the logo. Never behind body text.
Operational

Intelligence

Glows read best on Voyage / Signal / Crew. Never on resting body cards — reserve for primary CTA, live indicators, active module states.

08 — Naming convention

Three tiers, one pattern

Components always reference Tier 2 or Tier 3 — never Tier 1 directly.

Tier 1
Primitive ramps
Fixed values. Only referenced inside semantic token definitions. No theme awareness.
--{palette}-{step}
--voyage-500
--signal-400
--crew-300
--graphite-700
--beacon-400
--alert-500
10 palettes × 10 steps = 100 tokens.
Tier 2
Semantic tokens
Intent-driven, mode-aware — they switch value between light and dark. All components use these.
--color-{category}-{role}
--color-bg-canvas
--color-bg-surface
--color-text-primary
--color-border-focus
--color-action-primary
--color-feedback-success-bg
Categories: bg · text · border · action · feedback.
Tier 3
Effect tokens
Named effects & surfaces: the ladder, glass, gradients, glows, elevation. Maritime metaphors.
--{metaphor} / --{effect}-{palette}
--abyss · --canvas
--hull · --deck
--bridge · --helm
--gradient-spectrum
--glass-dk · --glow-voyage
--elev
Full descriptive words — never abbreviations.
Retired anti-patterns: --p500 → --voyage-500 · --n300 → --graphite-300 · --b-blue → --signal-400 · --dk0 → --canvas · --gS → --gradient-spectrum. Never color:var(--voyage-500) in components — use --color-action-primary; never raw hex like background:#0A0B1E — use --canvas.

Critical don'ts

White on signal
2.5:1 fail. Signal-400 takes navy #0A0B1E text only.
White on beacon
1.9:1 fail. Beacon always carries navy text — no exceptions.
White on crew-400
New in v3. Bright crew needs navy; white belongs on crew-500+.
White on cargo
Fails AA. Cargo-400 fills take navy text.
Body on spectrum
Unreadable mid-gradient. Spectrum is for bars & accents — never behind copy.
Pure black #000
Off-brand. Darkest value is abyss #06071A; canvas is #0A0B1E.
One more: logo hexes (#019934, #FF6600, #01ADFF) never style marketing surfaces — they live inside the mark only. Use module anchors instead.

Grade notes

Skin tones: preserve natural warmth — FrontM is human-centric. Never over-cool faces.

Highlights: cap at #D6DAEA; let signal-400 be the brightest accent point.

Broadcast: lift blacks to #0D0E22 for broadcast-safe output; #0A0B1E for web/streaming.

Saturation: moderate overall — electric blue and reef lime may push further.
